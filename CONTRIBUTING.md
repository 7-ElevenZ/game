# Contributing to 7-ElevenZ

Thanks for taking the time to contribute!

## Issues

Issues are very valuable to this project, because:

  - Ideas are a valuable source of contributions others can make
  - Problems show where this project is lacking
  - With a question you show where contributors can improve the user experience

Thank you for creating them!

## Pull Requests

Pull requests are a great way to get your ideas into this repository.

When deciding if we merge in a pull request, we look at the following:

### Does It State Intent?

You should be clear which problem you're trying to solve with your contribution.

For example:

> Add link to the Code of Conduct in README.md

is pretty vague and may not explain your intent.

> Add link to the Code of Conduct in README.md because users don't always look in the CONTRIBUTING.md

Tells us the problem that you have found, and the pull request shows us the action you have taken to solve it.

### Is It of Good Quality?

As long as:
- It follows the project's existing naming conventions and doesn't introduce new spelling errors in user-facing text (UI, error messages)
- The code is well formatted (if it's a code change)
- The commits aren't a mess

It will be considered good of quality.


### Does It Follow the Code of Conduct?

This repository has a [Code of Conduct](CODE_OF_CONDUCT.md), we recommend reading it to get a sense of what we expect from you.

## Local Setup

### Prerequesites
- Godot Engine 4.7 or newer (.NET Version): [Download][godot-download]
- Git

### Setup

1. Clone this repository
```bash
git clone https://codeberg.org/Demiomad/7-ElevenZ.git
cd 7-ElevenZ
```
2. Open Godot
3. Press `Import`
4. Navigate to the folder of the repo you just cloned, and select the `project.godot` file.
5. Press `Open`, and then `Import` (double click on the project afterwards!)
6. Build the project by clicking the hammer icon in the top, this should restore the necessary .NET packages.

[godot-download]: https://godotengine.org/download
